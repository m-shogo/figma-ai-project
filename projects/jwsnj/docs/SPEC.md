# 仕様（Human 指示 2026-11-20 + Figma 実装指示書 `294:852`）

## 共通

- 文字サイズは rem。ベース Theme の書き方に倣う
- 通常テキスト（見出し・本文・ナビ・ボタン・カードなど）の `line-height: 1`（100%）は原則 `1.3`（単位なし）に変更する。新規実装でも安易に `1` を指定しない（Human 2026-11-20）
- Figma 上の1行だけで判断せず、2〜3行の折り返し、CMS の長い文言、日本語・英語混在、PC/SP・中間幅、フォント差を想定。行の重なり、隣接要素、余白、固定高さ、`overflow` を実装前から確認し、スクリーンショットと実機で検証する。**jwsnj の新規実装では `white-space: nowrap` を使わない**
- Font Awesome など単体のアイコン glyph や明確な特殊意図がある要素のみ例外可。例外理由と検証結果を残す。デザイン一致のためにテキストを絶対配置や固定高さで押し込まない
- アイコンは Figma 上 Font Awesome（`arrow-right/f061` など）。読み込み方はベース Theme に合わせる

## 今回の制作前提（Human 2026-11-20）

- **正本はニュージャージーのFigma**。CODIAのベースTheme/ACFは「こう書く」という参考サンプル。実際の完成形はFigmaに合わせ、再利用・改修・不足分の追加を行う。不要なサンプルの機能・文言・画像・リンクを本番へ表示しない
- 実装順の先頭に **Figmaのカラー・書体/weight・画像/SVG・変数・共通部品の確認・導入・検証** を入れる。実測値と導入状況は `DESIGN_FOUNDATION.md` に記録し、正本が確定してから各ページを実装
- PCのメニューは hover、SPはクリック/タップで開閉。現在はこれを基本動作とし、不要な追加仕様を作り込まない
- 文字の150〜200%拡大を行う専用QAは不要。**2〜3行の自然な折り返し、PC/SPと中間幅、通常文字サイズでの崩れ対策は必要**
- 今回は通常投稿・固定ページのみを想定し、独自CPTは追加しない。取り込んだイベントCPTと `event_cat` の有効化は停止。実装例の関数は参照用に残す
- URL構成の未決事項はHumanが後日指示する。未確定リンクは適当なslugで埋めず、依存しない部分を進める
