# ディレクトリーマップ（下書き）

Figma のメニュー文言から作った下書き。**URL（slug）はまだ決まっていない**。Human からマップが届いたらこのファイルを差し替える。それまで URL を発明しない。

## WordPress のメニュー（管理画面で作る）

| メニュー | 出る場所 | Figma |
|---|---|---|
| PC ヘッダー | PC ヘッダー（4 項目） | `599:2726` menu_open |
| SP ハンバーガー | SP メニュー | `480:3954` menu_sp |
| フッター | フッターのサイトマップ | footer `221:335` |

### PC ヘッダー（4 項目）

- 学校案内（ドロップダウン）
  - 学校概要
  - 教育方針
  - 教育環境
  - 交通・アクセス
- 教育内容
- コース紹介（ドロップダウン。中身は Figma に無い）
- 入学・編入案内（ドロップダウン。中身は Figma に無い）

ヘッダー右上の小リンク: 入学案内 / 保護者専用 / 採用情報。CTA ボタン「編入・学校見学はこちら」。これらが WP メニューか固定リンクかは未定。
