## 2026-07-24 — Updated Auto Layout closer to CSS

Figma reports an updated Auto Layout option intended to close gaps between Figma layout behavior and CSS.

Important compatibility detail:

- existing frames stay on the legacy version unless updated
- new frames use the updated version automatically
- reverting to legacy remains possible until January 2027

### Research implications

- reference manifests should record whether relevant frames are legacy/updated/mixed when observable
- old Auto Layout → CSS failure observations need retesting
- two visually identical references may not carry identical layout semantics
- don't make permanent conclusions from pre-update Auto Layout experiments

## 2026-07-16 — Code-backed screens return with more variable binding / Auto Layout

When code-backed screens are brought onto the Figma canvas, Figma says colors, type, and spacing now bind to many existing variables rather than arriving only as hardcoded values. More imported frames also receive Auto Layout.

Applies to flows including:

- Make preview → design layers
- code → design through Figma MCP
- live web capture → editable layers

### Research implications

This materially raises the potential value of the future Code → Figma verification/review loop.

Old findings such as:

- "code-to-canvas requires lots of token rebinding"
- "imported editable frames need extensive manual layout cleanup"

must be retested under current tooling.

## 2026-07-09 — GPT-5.6 available in Figma Make

Figma Make added GPT-5.6 to its model picker.

### Research implication

If Figma Make becomes part of future comparison workflows, exact model selection/date must be captured. Historical Make quality should not be compared without model metadata.

## 2026-07-07 — Parallel AI image edits

Figma added the ability to run multiple AI image edits in parallel while continuing design work.

### Research implication

The future image-reference track should not assume image workflows are static or single-step. Image editing/generation capability can become part of the evidence or repair pipeline, but must remain separated from source-of-truth design reproduction unless intentionally tested.

## 2026-06-24 — Code layers / richer code-and-canvas workflows

Figma announced code layers on the canvas as part of Config 2026.

### Research implication

Long-term evaluation may compare:

- native design layers
- code-backed/code-layer representations
- running browser implementation

without assuming only one representation is useful for review.

## 2026-06-18 — Web search in Figma design agent

Figma's design agent gained web search access.

### Research implication

Future design-agent experiments may include current external context, but this repo must distinguish:

- reference reproduction
- design research/redesign

Web search should not cause the agent to silently redesign a frozen reference.

## Current MCP capability note

The Figma MCP developer documentation explicitly describes the platform as rapidly improving and currently beta for some agent functionality.

Current documented direction includes:

- structured design context
- screenshots and metadata
- Code Connect mappings
- native Figma canvas write tools
- creating/editing components, variables, styles and Auto Layout
- code/web interface → editable Figma workflows on supported clients

### Operational rule

Before a significant Figma experiment, compare this snapshot against current release notes and create a new dated snapshot if material capabilities changed.

Do not edit this historical snapshot to pretend the old experiment ran with new capabilities.
