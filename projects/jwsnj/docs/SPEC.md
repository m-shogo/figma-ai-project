# 仕様（Human 指示 2026-11-20 + Figma 実装指示書 `294:852`）

## 共通

- 文字サイズは rem。ベース Theme の書き方に倣う
- 通常テキスト（見出し・本文・ナビ・ボタン・カードなど）の `line-height: 1`（100%）は原則 `1.3`（単位なし）に変更する。新規実装でも安易に `1` を指定しない（Human 2026-11-20）
- Figma 上の1行だけで判断せず、2〜3行の折り返し、CMS の長い文言、日本語・英語混在、PC/SP・中間幅、フォント差を想定。行の重なり、隣接要素、余白、固定高さ、`overflow`、`nowrap` を実装前から確認し、スクリーンショットと実機で検証する
- Font Awesome など単体のアイコン glyph や明確な特殊意図がある要素のみ例外可。例外理由と検証結果を残す。デザイン一致のためにテキストを絶対配置や固定高さで押し込まない
- アイコンは Figma 上 Font Awesome（`arrow-right/f061` など）。読み込み方はベース Theme に合わせる
