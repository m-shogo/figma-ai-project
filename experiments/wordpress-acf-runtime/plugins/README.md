# メニューのみ インポート/エクスポート

WordPress 管理画面の **外観 → メニュー** だけを JSON で書き出し・読み込みするプラグイン。

## 配布 ZIP（これをアップロードする）

[`menu-only-import-export.zip`](./menu-only-import-export.zip)

管理画面: **プラグイン → 新規追加 → プラグインのアップロード**

有効化後: **ツール → メニューの書き出し**

読み込み時のチェック「リンク先が無くても、名前と階層は残す」を入れると、このサイトに無い固定ページは項目ごと消さず、**カスタムリンク**として名前と入れ子を残します。無いページの投稿 ID には紐づけません。あとから 外観 → メニュー で付け直せます。
