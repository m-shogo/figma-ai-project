# Candidate Rules

ここには、Observationより強いがまだ汎用playbookとして証明不足のruleを置く。

## Entry gate

- target failureが明確
- isolated changeで改善した
- before/after evidenceあり
- clean replayを最低1回通した
- scope/known limitsを記録した

## Promotion

別reference/別案件または十分に異なるcontextで再現したら `../proven/` へ昇格を検討する。
